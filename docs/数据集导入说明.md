# CelebA 与 VGGFace2 导入说明

## 当前导入策略

人物元数据全部录入，参考图默认每个身份最多保留 5 张。系统在导入时执行
YuNet 人脸检测和 SFace 向量提取；检测失败的图片不会进入数据库。原始大数据集
不复制到 Git，下载文件、参考图、SQLite 和断点都位于 `data/`。

| 数据集 | 身份数 | 上游体积 | 本地名称 | 默认许可标记 |
|---|---:|---:|---|---|
| CelebA | 10,177 | 约 11.7 GB | 匿名 `CelebA #xxxxx` | 非商业研究 |
| VGGFace2 | 9,131 | 约 40.2 GB | `identity_meta.csv` 姓名 | CC BY-NC 4.0 镜像标记，需复核原始条款 |

CelebA 源：<https://huggingface.co/datasets/flwrlabs/celeba>  
VGGFace2 镜像：<https://huggingface.co/datasets/ProgramComputer/VGGFace2>  
VGGFace2 论文：<https://arxiv.org/abs/1710.08092>

## 可恢复性

- CelebA 扫描位置：`data/import_jobs/celeba.json`；重复运行会从断点继续。
- VGGFace2 下载使用 `curl --continue-at -`；重复运行自动续传不完整归档。
- 人物外部 ID 和参考图来源 URL 都具有唯一约束，重复运行不会产生重复记录。
- 批量任务完成后可调用 `POST /api/library/reload`，或重启服务，刷新内存索引。

如需重新扫描 CelebA 前面的数据来补足检测失败身份：

```bash
python scripts/import_research_datasets.py celeba \
  --images-per-identity 5 --reset-scan
```

## 使用边界

这些数据集适合研究和内部算法评估，不等于取得了肖像、公开权、隐私或商业代言
授权。相似度结果也不是身份确认或法律侵权结论。商用前应逐项确认数据集条款、
图片版权、目标司法辖区的人脸生物特征处理规则，以及删除和异议处理机制。
