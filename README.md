## 📋 What this tool does

When you create content using artificial intelligence, you might accidentally create characters that resemble real actors or celebrities. This causes legal issues regarding the right of publicity. This tool helps you catch these similarities early. 

The software uses facial recognition technology to compare the face in your image to a known collection of faces. If the system finds a match, it provides a reference link. You must review the results yourself to decide if the likeness creates a risk.

No. Once you install the core components, the facial recognition engine works offline. You only need the internet to perform the initial setup or to view the reference links provided in the results.

**What should I do if the app crashes?**
Close the app and restart your computer. If the problem continues, delete the app, download a fresh copy from the link provided in this guide, and run the installer again.

**Can I scan multiple images at once?**
Yes. You can drag and drop a folder containing several images into the application window. The app will process them one by one.

**Does this software store my images?**
No. The software analyzes the image data to create a technical map of the face but does not save the actual image file to a database.
